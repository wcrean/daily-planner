# Daily Planner

Front-end prototype for a personal daily planner.

## v0.1.0

Includes:
- Adaptive greeting based on local time
- Current date
- Current-location permission button with Morristown, NJ fallback
- Sample weather card
- Sample Today agenda
- Mobile-first responsive layout

## Next steps

1. Add secure Cozi ICS proxy and live event parsing.
2. Add live weather using the user's current coordinates or Morristown fallback.
3. Replace all sample data with live data.
